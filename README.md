# Group — official site

Готовый одностраничный сайт музыкальной группы в тёмной эстетике, собранной вокруг загруженного логотипа.

## Запуск
Просто откройте `index.html` в браузере.

## Что заменить
- `assets/logo.png` — логотип уже добавлен.
- Название группы, тексты и даты — в `index.html`.
- Ссылки Spotify / VK / Telegram / YouTube — в `index.html`.
- `booking@example.com` — настоящий email для букинга.

Сайт адаптивный: работает на компьютере и телефоне.
